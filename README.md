# TACTICA 2026: 차라리 내가 감독함

DAKER `월간 해커톤: 내가 축구 감독이라면 - 월드컵 전술 웹서비스 챌린지` 제출 준비용 프로젝트입니다.

## 현재 준비된 자료

- `docs/01-기획서-원문.md`: 제출용 기획서의 원문
- `output/pdf/TACTICA-2026-차라리-내가-감독함-기획서.pdf`: 최종 제출 기획서 PDF
- `docs/02-최종제출-체크리스트.md`: 배포 URL, GitHub, YouTube 링크를 확정하는 제출 체크리스트
- `docs/03-시연영상-대본.md`: 필수 흐름을 포함한 90초 시연 대본
- `data/world-cup-2026.json`: 2026 월드컵 32개국 실제 팀·선수·대회 기록 기반 전술 데이터
- `scripts/build_world_cup_32_data.mjs`: CC0 원천 CSV에서 32개국 데이터와 TACTICA 파생 지수를 다시 생성하는 변환 스크립트
- `docs/05-실데이터-전환가이드.md`: 대회 제공·사용 허가 데이터로 교체할 때의 검증 및 표기 가이드
- `docs/06-출처-및-라이선스.md`: 코드·데이터·외부 자산의 출처 및 라이선스 기록
- `docs/07-대회적합성-점검.md`: 공식 요건 대비 구현 현황과 제출 전 차단 요인

## 콘셉트

**TACTICA 2026: 차라리 내가 감독함**은 사용자가 감독이 되어 상대 전력을 확인하고, 선수를 배치하며, 포메이션과 전술 지시를 바꾼 뒤 전술 효과를 즉시 확인하는 웹서비스입니다.

핵심 사용자 흐름은 다음과 같습니다.

1. 경기와 상대 팀을 선택한다.
2. 전술 보드에서 선수를 드래그해 선발 11명을 구성한다.
3. 포메이션·전술 지시를 바꾸고, 공격·점유·수비 지표 변화를 확인한다.
4. 전술 결과와 교체 제안을 확인하고 다른 시나리오와 비교한다.

## 데이터 사용

기본 실행 데이터는 `data/world-cup-2026.json`입니다. 2026 월드컵 본선 48개국 중 **개막 전 FIFA 랭킹 상위 32개국**을 선택 풀로 구성했습니다. 각 국가는 FIFA 랭킹·Elo·조·연맹·감독, 선수 26명, 실제 대회 출전·득점·도움·선방, 팀 평균 점유·슈팅·코너·파울 기록을 포함합니다. `R01` 같은 표기는 공식 등번호가 아닌 **데이터셋 등록 순번**입니다.

`OVR`과 7개 능력치는 EA SPORTS FC/FIFA의 공식 게임 능력치가 아닙니다. 실제 포지션·국가대표 기록·시장가치·이번 대회 출전 기록을 규칙으로 환산한 **TACTICA 파생 전술 지수**이며, 컨디션·세부 포지션·전술 배치·시뮬레이션 결과는 서비스 모델 값입니다. 실제 경기 결과 예측이나 공식 시뮬레이션을 주장하지 않습니다. 상세 출처·가공 기준은 `docs/08-실데이터-출처-및-가공기록.md`에서 관리합니다.

앱 상단 `DATA · METHOD`에서 현재 데이터 상태, 출처, 전술 지수 산정 기준, 계산 단계, 심사자 체험 흐름을 확인할 수 있습니다. JSON 파일은 같은 화면에서 구조 검증 후 교체할 수 있으며, 원천 데이터가 갱신되면 `npm run data:build`와 `docs/08`을 함께 갱신합니다.

## MVP 실행

별도 패키지 설치가 필요 없습니다. Node.js 18 이상에서 아래 명령을 실행합니다.

```bash
npm run dev
```

브라우저에서 `http://localhost:4173`을 열면 됩니다.

### 현재 동작하는 기능

- 32개국 풀에서 홈팀·원정팀을 직접 선택하는 자유 매치업
- 선수 카드 드래그앤드롭 또는 클릭 배치
- 23개 FIFA 스타일 포메이션 전환과 자유 포지션 배치
- 선수별 컨디션·체력·포지션 적합도 표시
- 선수 선택 시 핵심 스탯 6개·역할 태그·상세 상태 표시
- 선발 XI·후보 분리 탭, 포지션 필터, 상세/간단 카드 밀도 전환
- 압박, 수비 라인, 공격 폭, 템포, 빌드업 전술 설정
- 90분 자동 경기 재생, 하프타임·경기 중 교체, 전술·포메이션 변경
- 교체 5명 제한·재투입 방지 및 변경 뒤 다음 전술 구간 결과 재계산
- 전술 결과 시뮬레이션: 예상 스코어, xG, 공격·점유·수비·역습 위험, 이벤트 타임라인
- 슈팅, 유효 슈팅, 선방, 코너킥, 반칙 경기 결과 지표
- 큰 결과 분석 카드: 전술 요약·경기 지표·경기 흐름·피트니스·감독 리포트 탭
- 감독 의사결정 로그, 최대 2개 전술안 A/B 비교, Markdown 리포트 다운로드
- 브라우저 자동 저장·복원과 현재 전술 설정 공유 링크
- 데이터 출처·계산 근거 공개, JSON 데이터 세트 구조 검증 및 교체

구체적인 선수·포메이션 설계는 `docs/04-선수·포메이션-설계.md`에서 확인할 수 있습니다.
