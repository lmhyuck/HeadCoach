# TACTICA 2026: 차라리 내가 감독함

`TACTICA 2026: 차라리 내가 감독함`은 DAKER 월간 해커톤 `내가 축구 감독이라면 - 월드컵 전술 웹서비스 챌린지` 제출용 프로젝트입니다.

## 프로젝트 개요

이 프로젝트는 사용자가 감독 역할을 맡아 상대 전력을 분석하고, 선수를 배치하며, 전술을 조정하고, 결과를 비교해볼 수 있는 웹 기반 전술 체험 서비스를 목표로 합니다.

- 실제 월드컵 2026 데이터를 기반으로 한 팀·선수 선택과 전술 시뮬레이션
- 드래그앤드롭 기반 선수 배치 및 포메이션 전환
- 전술 설정에 따른 경기 지표 변화 즉시 확인
- A/B 전술 비교와 전술 리포트 생성

## 콘셉트

웹 앱은 감독이 되어 다음 과정을 체험하도록 설계되었습니다.

1. 경기 대상 팀을 선택하고 상대 전력을 파악한다.
2. 선수 배치를 구성하고 포메이션을 조정한다.
3. 전술 지시를 변경하며 경기 지표 변화를 확인한다.
4. 경기 결과 요약과 교체 제안을 검토한다.

## 데이터 전략

기본 데이터는 `data/world-cup-2026.json`이며, 2026 월드컵 본선 48개국 중 개막 전 FIFA 랭킹 상위 32개국을 중심으로 구성했습니다.

포함 항목:

- 국가별 FIFA 랭킹, Elo, 조 정보, 연맹, 감독 정보
- 선수 26명 프로필, 출전 기록, 득점/도움/선방 데이터
- 팀 평균 점유율, 슈팅, 코너킥, 파울 등 경기 지표

데이터 모델링:

- `OVR`과 7개 능력치는 EA SPORTS FC/FIFA의 공식 게임 능력치가 아니라, 실제 기록·시장가치·대회 출전 정보를 기반으로 산정한 TACTICA 파생 지수입니다.
- 컨디션, 세부 포지션 적합도, 전술 배치, 시뮬레이션 결과는 서비스 모델 값입니다.
- 실제 경기 예측이나 공식 시뮬레이션 결과를 주장하지 않습니다.

상세 출처와 가공 기준은 `docs/08-실데이터-출처-및-가공기록.md`에서 확인할 수 있습니다.

## 실행 방법

Node.js 18 이상에서 아래 명령을 실행합니다.

```bash
npm run dev
```

웹 브라우저에서 `http://localhost:4173`을 열면 됩니다.

## 구현된 핵심 기능

- 32개국 풀에서 홈/원정팀을 선택하는 자유 매치업
- 드래그앤드롭 및 클릭으로 선수 배치
- 23개 FIFA 스타일 포메이션과 자유 포지션 배치
- 컨디션·체력·포지션 적합도 및 핵심 스탯 표시
- 압박, 수비 라인, 공격 폭, 템포, 빌드업 전술 설정
- 90분 자동 경기 재생, 하프타임/교체, 전술 수정
- 5명 교체 제한 및 재투입 방지
- 전술 결과 시뮬레이션: 예상 스코어, xG, 공격·점유·수비·역습 위험, 이벤트 타임라인
- 분석 리포트: 전술 요약, 경기 지표, 경기 흐름, 피트니스, 감독 리포트
- 전술 A/B 비교 및 Markdown 리포트 다운로드
- 브라우저 자동 저장/복원과 전술 공유 링크
- JSON 데이터 구조 검증 및 출처/계산 근거 공개

구체적인 선수와 포메이션 설계는 `docs/04-선수·포메이션-설계.md`에서 확인할 수 있습니다.

## 제출 준비 체크리스트

제출 직전에는 아래 항목을 확인하여 심사자가 전체 흐름을 명확히 이해할 수 있도록 합니다.

- `DATA · METHOD` 화면에 현재 데이터 상태, 출처, 가공 기준, 계산 원리가 명확히 표시되었는지 확인합니다.
- `docs/02-최종제출-체크리스트.md`에 배포 URL, GitHub 링크, 시연 영상 링크를 정확히 기입하고 모두 정상 동작하는지 테스트합니다.
- 배포 URL을 비로그인/시크릿 창에서 열어 접근성과 동작을 점검합니다.
- `scripts/generate_planning_pdf.py`를 실행하여 PDF의 팀명, 링크, 문구가 최종 버전인지 확정합니다.
- `docs/06-출처-및-라이선스.md`와 `docs/08-실데이터-출처-및-가공기록.md`에 출처 및 라이선스 정보가 제출 기준에 부합하는지 확인합니다.
- 제출 이후에는 배포와 저장소를 동결하고, 제출 직전까지 추가 커밋을 자제합니다.
