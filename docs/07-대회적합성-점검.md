## 이번 점검에서 보완한 항목

- `DATA · METHOD` 모달: 데이터 상태·출처·갱신일·이용 조건·계산 단계·심사자 체험 흐름을 앱 안에서 공개
- JSON 데이터 교체 입력: 최종 데이터 세트를 별도 키 없이 검증해 로드할 수 있도록 준비
- 데이터 구조 검증 강화: 팀, 11인 선발, 포메이션 슬롯, 시나리오 참조, 선수 능력치 확인
- 추천 기능 투명화: 외부 AI로 오인하지 않도록 `규칙 기반 전술 어시스턴트`로 표기
- 코드 라이선스와 데이터·외부 자산 출처 기록 추가

## 남은 제출 차단 요인

1. 배포 URL, GitHub URL, YouTube 시연 영상 URL 확정.
2. CC0 원천 저장소와 대회 공지의 데이터·저작권 조건을 제출 직전에 재확인.
3. 제출 마감 뒤 GitHub 커밋 금지. 공식 안내의 마감 시각을 제출 직전 다시 확인.
