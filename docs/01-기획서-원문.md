# TACTICA 2026: 차라리 내가 감독함

> 제출 전 입력: 팀명 `[팀명]` / 대표자 `[이름]` / 배포 URL `[https://...]`

## 1. 서비스 개요

TACTICA 2026은 사용자가 축구 감독이 되어 상대 팀 전력을 파악하고, 직접 선수를 배치한 뒤 전술 결과를 확인하는 인터랙션형 웹서비스다. 단순히 포메이션을 고르는 데 그치지 않고, 선발 명단·선수 역할·전술 지시를 바꾸면 공격, 점유, 수비의 균형과 예상 경기 흐름이 즉시 바뀌도록 설계한다.

## 2. 문제와 해결 방향

축구 전술 콘텐츠는 보통 전문가의 해설을 수동적으로 소비하는 데 머문다. 사용자가 “내가 감독이라면?”이라는 질문에 직접 답하려면, 선수의 특성과 상대 팀의 약점을 함께 고려해 의사결정을 내리고 그 결과를 바로 확인할 수 있어야 한다.

TACTICA 2026은 이 과정을 `상대 분석 → 전술 구성 → 전술 효과 확인 → 시나리오 비교`라는 짧은 루프로 만든다.

## 3. 감독 경험 설계 의도

- **내 결정이 보인다**: 선수를 드래그해 경기장 위에 배치하고 역할을 지정한다.
- **결과를 이해한다**: 전술을 바꾸면 공격·점유·수비 지표와 전술 설명이 함께 바뀐다.
- **다시 시도한다**: 저장한 안과 현재 안을 비교해 “내가 감독이었다면”의 가설을 검증한다.

## 4. 페이지 구성

| 화면 | 목적 | 핵심 요소 |
|---|---|---|
| 홈/경기 선택 | 시작 상황 설정 | 경기 카드, 상대 분석 요약, 난이도 |
| 전술 보드 | 선수·포메이션 구성 | 경기장, 드래그앤드롭, 포메이션, 벤치 |
| 전술 지시 | 세부 전략 설정 | 압박, 수비 라인, 공격 폭, 템포 |
| 결과 분석 | 전술 효과 설명 | 공격·점유·수비 지표, 장단점, 교체 제안 |
| 시나리오 비교 | 의사결정 회고 | A/B 전술 비교, 저장, 다시 편성 |

## 5. 핵심 인터랙션 명세

1. **선수 배치**: 벤치의 선수를 드래그해 포지션 슬롯에 놓고, 포지션 적합도 색상으로 피드백한다.
2. **포메이션 전환**: 4-3-3, 4-2-3-1, 3-4-3을 선택하면 슬롯이 재배치되고 적합 선수 후보가 제안된다.
3. **전술 지시 변경**: 압박, 수비 라인, 공격 폭, 템포를 선택하면 전술 지표와 설명 카드가 실시간으로 갱신된다.
4. **전술 결과 확인**: 선수 능력치, 포지션 적합도, 상대 전력, 전술 지시를 조합해 전술 밸런스와 예상 장면을 제시한다.
5. **시나리오 비교**: 서로 다른 두 전술을 저장해 지표 차이와 선택 이유를 비교한다.

## 6. 데이터 활용 방식

기본 데이터는 2026 월드컵 본선 48개국 중 개막 전 FIFA 랭킹 상위 32개국의 실제 선수·팀·대회 기록이다. 국가별로 선수 26명, FIFA 랭킹·Elo·조·연맹·감독, 이번 대회 선수 출전·득점·도움·선방과 팀 점유·슈팅·코너·파울 지표를 연결한다. 전술 보드에 필요한 세부 포지션과 전술 지수는 원천 사실 필드와 분리해 TACTICA 규칙으로 가공한다.

- 선수 능력치: pace, shooting, passing, dribbling, defense, physical, positioning
- 팀 정보: 기본 포메이션, 전술 성향, 팀 강점·약점
- 경기 정보: 상대 팀, 경기 상황, 미션, 예상 난이도
- 전술 계산: 포지션 적합도와 선수 능력치, 전술 지시의 가중 합산

원본 제공처, 이용 조건, 수집일, 가공 범위는 `docs/08-실데이터-출처-및-가공기록.md`에 기록한다. 심사자 키 없이 정적 JSON으로 동작하며, 앱의 `DATA · METHOD` 화면과 결과 리포트에는 같은 데이터 상태와 출처를 표시한다.

## 7. 주요 사용 흐름

1. 사용자가 `대한민국 vs 브라질` 시나리오를 고른다.
2. 상대 팀의 빠른 측면 공격이라는 요약을 확인한다.
3. 4-2-3-1을 선택하고 선발 선수를 경기장에 배치한다.
4. 수비 라인을 낮추고 압박을 중간으로 바꾸면 수비 안정성은 높고 공격 전개는 낮아지는 변화를 확인한다.
5. 측면 수비 보강 또는 공격형 교체라는 제안을 보고 A/B 전술을 비교한다.

## 8. 구현 범위와 완성 기준

MVP에서는 하나의 전술 보드에서 완성도 높은 조작 경험을 제공하는 데 집중한다. 실제 서버 회원가입, 결제, 외부 키 입력 없이 브라우저에서 즉시 실행되며, 개발 데이터와 최종 데이터 모두 같은 스키마로 동작한다.

완성 기준은 다음과 같다.

- 드래그앤드롭 배치와 포메이션 전환이 오류 없이 동작한다.
- 전술 변경에 따른 결과가 즉시 이해 가능한 형태로 표시된다.
- 모바일·데스크톱 주요 브라우저에서 핵심 흐름을 실행할 수 있다.
- README에 실행 방법, 데이터 출처/라이선스, 사용 기술을 적는다.
