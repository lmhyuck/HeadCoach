# TACTICA 2026 선수·포메이션 설계 v1

## 설계 원칙

이 서비스는 축구 게임의 모든 세부 스탯을 재현하지 않는다. 사용자가 전술을 바꾸었을 때 **왜 결과가 달라졌는지 즉시 이해**하도록, 전술 결정에 직접 연결되는 값만 사용한다.

- 선수 카드에는 핵심 값만 먼저 보여 준다.
- 각 값은 전술 결과 화면의 공격·점유·수비 지표 중 최소 하나에 영향을 준다.
- 스탯이 많아 보이는 대신 설명되지 않는 구조는 피한다.

---

## 1. 선수 스탯

### MVP 핵심 스탯 6개

| 스탯 | 의미 | 주로 영향을 주는 결과 |
|---|---|---|
| 속도 (`pace`) | 스프린트, 뒷공간 침투, 복귀 | 역습, 측면 돌파, 수비 전환 |
| 슈팅 (`shooting`) | 마무리와 중거리 정확도 | 득점 기대, 공격력 |
| 패스 (`passing`) | 짧은 패스·전환 패스 정확도 | 점유 전개, 기회 창출 |
| 드리블 (`dribbling`) | 압박 회피와 1대1 돌파 | 전진, 측면 공격, 점유 유지 |
| 수비 (`defense`) | 태클, 차단, 마킹 | 수비 안정성, 실점 위험 |
| 피지컬 (`physical`) | 경합, 버티기, 공중볼 | 세트피스, 압박 저항, 후반 안정성 |

### 보조 스탯 1개

| 스탯 | 사용 방식 |
|---|---|
| 위치 선정 (`positioning`) | 포지션 적합도와 공격·수비 가담 판단의 보정값. 상세 카드에서만 표시하고, 첫 화면의 핵심 비교값으로는 쓰지 않는다. |

`overall`은 선수를 빠르게 비교하기 위한 표시값이다. 실제 시뮬레이션은 종합 능력치가 아니라 위의 개별 스탯을 사용한다.

### 스탯별 영향 예시

```text
공격 지표 = 슈팅 + 드리블 + 공격진 속도 + 전술 보정
점유 지표 = 패스 + 드리블 + 중원 위치 선정 + 전술 보정
수비 지표 = 수비 + 피지컬 + 수비진 속도 + 전술 보정
```

세 수치는 실제 축구 통계가 아니라, 사용자가 전술 변화를 이해하기 위한 **설명 가능한 서비스 지표**다.

## 2. 선수 성향·역할

성향은 능력치를 대체하지 않는다. 같은 스탯을 가진 선수라도 전술에서 어떤 행동을 우선하는지 보여 주는 역할 태그다.

### 사용 규칙

- 선수당 **주 역할 1개**, 보조 태그는 필요할 때만 1개를 둔다.
- 역할은 특정 전술 옵션과 맞을 때만 작은 보정값을 준다.
- 서로 다른 역할을 여러 개 겹쳐 넣지 않는다.

### 역할 태그 목록

| 구분 | 역할 | 전술 효과 |
|---|---|---|
| 공격수 | 피니셔 | 박스 안 슈팅·득점 기대 상승 |
| 공격수 | 압박형 공격수 | 높은 압박 시 수비 시작점 강화, 체력 소모 증가 |
| 공격수 | 타깃형 공격수 | 피지컬 경합과 크로스 전개 강화 |
| 공격수 | 폴스 나인 | 중원 연계와 점유 전개 강화, 박스 점유는 감소 |
| 윙어 | 측면 돌파형 | 넓은 공격 폭·역습에서 돌파 확률 상승 |
| 윙어 | 인버티드 윙어 | 안쪽 침투 시 슈팅·연계 강화 |
| 미드필더 | 플레이메이커 | 패스 전개와 기회 창출 강화 |
| 미드필더 | 박스 투 박스 | 공수 전환 강화, 체력 소모 증가 |
| 미드필더 | 앵커 | 수비 라인 보호와 역습 차단 강화 |
| 수비수 | 오버래핑 풀백 | 넓은 공격 폭에서 지원 강화, 뒷공간 위험 증가 |
| 수비수 | 수비형 풀백 | 수비 안정성 강화, 공격 가담 감소 |
| 수비수 | 빌드업 수비수 | 후방 패스 전개 강화, 높은 압박에는 위험 증가 |
| 골키퍼 | 스위퍼 키퍼 | 높은 수비 라인 뒷공간 대응 강화 |
| 골키퍼 | 선방형 키퍼 | 박스 안 실점 위험 감소 |

## 3. 선수 상태

상태는 경기마다 달라지는 값이며, 감독의 선발·교체 결정을 만드는 요소다. MVP에서는 세 가지만 사용한다.

| 상태 | 범위 | 효과 | UI 표현 |
|---|---|---|---|
| 컨디션 (`form`) | `good` / `normal` / `poor` | 전체 핵심 스탯에 +6% / 0% / -6% 보정 | 초록·회색·주황 화살표 |
| 체력 (`stamina`) | 0-100 | 낮을수록 속도·수비·압박 효율 감소 | 원형 게이지 |
| 포지션 적합도 | 50 / 70 / 85 / 100 | 슬롯 위치와 주·부 포지션 일치 정도 | 빨강·주황·노랑·초록 테두리 |

### 체력 규칙

| 체력 | 전술 영향 | 감독 피드백 |
|---|---|---|
| 70 이상 | 감점 없음 | 정상 출전 가능 |
| 40-69 | 속도·수비·압박 효율 5% 감소 | 교체 후보 검토 |
| 0-39 | 속도·수비·압박 효율 12% 감소 | 교체 권장 |

체력 소모는 실제 물리 시뮬레이션 대신 전술에 따라 계산한다. 예를 들어 `높은 압박 + 빠른 템포`는 공격수와 미드필더의 체력을 더 많이 소모시키며, 후반 시나리오에서는 교체 제안의 근거가 된다.

## 4. 포메이션

초기 MVP는 아래 세 포메이션만 제공한다. 선택지는 적지만, 각 포메이션의 장단점이 뚜렷해 전술 선택의 의미가 생긴다.

### 4-2-3-1 - 기본·안정형

```text
                 ST
        LW/AM    CAM    RW/AM
              LDM  RDM
      LB       LCB  RCB       RB
                 GK
```

- 강점: 중원 보호, 상대 윙어 대응, CAM을 활용한 공격 전개
- 위험: 최전방이 고립될 수 있고 측면 공격 숫자가 부족할 수 있음
- 추천 상황: 강팀 상대, 선제 실점 방지, 후반 교체 전 기본 전술

### 4-3-3 - 점유·측면 공격형

```text
          LW       ST       RW
            LCM    CM    RCM
      LB       LCB  RCB       RB
                 GK
```

- 강점: 좌우 폭 확보, 윙어 돌파, 중원 점유
- 위험: 중앙 수비형 미드필더가 없으면 역습에 약함
- 추천 상황: 점유율을 가져가야 할 때, 상대 풀백 뒷공간 공략

### 3-4-3 - 공격적 압박형

```text
          LW       ST       RW
      LWB     LCM  RCM     RWB
            LCB  CB  RCB
                 GK
```

- 강점: 전방 숫자와 측면 윙백을 활용한 강한 압박
- 위험: 윙백 뒷공간, 수비 전환, 체력 소모
- 추천 상황: 득점이 필요한 후반, 상대가 낮게 내려앉은 경우

### 포지션 적합도 규칙

| 배치 | 적합도 | 결과 |
|---|---|---|
| 주 포지션 | 100 | 능력치 100% 반영 |
| 유사 포지션 | 85 | 작은 감점, 전술 선택에 따라 보완 가능 |
| 부 포지션 | 70 | 일부 능력치 감점, 역할 태그로 보완 가능 |
| 비적합 포지션 | 50 | 해당 라인 지표 하락, 경고 표시 |

## 5. 전술 옵션과 연결

포메이션을 고른 뒤에만 전술 옵션을 조정한다. 각 옵션은 모든 스탯을 건드리지 않고, 관련된 역할·상태에만 영향을 준다.

| 옵션 | 선택값 | 대표 영향 |
|---|---|---|
| 압박 | 낮음 / 중간 / 높음 | 수비 시작점, 체력 소모, 역습 위험 |
| 수비 라인 | 낮음 / 보통 / 높음 | 뒷공간 위험, 상대 진영 압박 |
| 공격 폭 | 좁게 / 보통 / 넓게 | 윙어·풀백 활용, 중앙 밀집도 |
| 템포 | 느리게 / 보통 / 빠르게 | 기회 수, 패스 실수, 체력 소모 |
| 빌드업 | 점유 / 혼합 / 직선 | 패스형 미드필더·빠른 공격수 활용도 |

## 6. 화면에 보여 줄 정보 우선순위

1. **선발 선수 카드**: 포지션, 종합 능력치, 컨디션, 체력
2. **선수 상세 카드**: 핵심 스탯 6개, 역할 태그, 부 포지션
3. **전술 보드 경고**: 비적합 포지션, 체력 부족, 역할 충돌
4. **결과 화면**: 공격·점유·수비 변화와 그 원인 2~3개

처음부터 숨은 변수와 복잡한 계산식을 공개하지 않는다. 사용자가 "윙어의 속도와 넓은 공격 폭 때문에 측면 위협이 올랐다"처럼 결과를 자연스럽게 이해하게 만드는 것이 목표다.
