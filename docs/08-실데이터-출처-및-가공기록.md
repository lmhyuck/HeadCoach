# 32개국 실제 데이터 출처 및 가공 기록

## 적용 범위

- 기본 파일: `data/world-cup-2026.json`
- 생성 스크립트: `scripts/build_world_cup_32_data.mjs`
- 적용일: 2026-07-23
- 대상: 2026 월드컵 본선 48개국 가운데 개막 전 FIFA 랭킹 상위 32개국
- 규모: 팀 32개국, 선수 832명(팀당 26명)

## 원천 데이터

원천은 [Mominullptr FIFA World Cup 2026 Dataset](https://github.com/mominullptr/FIFA-World-Cup-2026-Dataset)이다. 데이터셋은 **CC0-1.0 Public Domain Dedication**으로 공개되어 있으며, 48개국 1,248명과 실제 대회 팀·선수·경기 기록을 제공한다.

사용한 CSV는 다음과 같다.

- `teams.csv`: 국가명, FIFA 코드, 조, 연맹, 개막 전 FIFA 랭킹, Elo, 감독
- `squads_and_players.csv`: 선수명, 원문 포지션, 소속, 시장가치, A매치, 생년월일, 신장, 대표팀 득점
- `player_stats.csv`: 이번 대회 출전·선발·시간·득점·도움·선방
- `match_team_stats.csv`: 경기별 점유율·슈팅·유효슈팅·코너·파울·선방
- `match_lineups.csv`, `matches.csv`: 실제 완료 경기의 최근 선발 XI

원천 데이터의 최종 확인일은 2026-07-19이며, 이 프로젝트의 스냅샷 수집일은 2026-07-23이다.

## 가공 원칙

- 32개국은 `teams.csv`의 `fifa_ranking_pre_tournament` 오름차순 상위 32개 참가국으로 선택한다.
- 기본 선발 XI는 팀별 가장 최근 완료 경기의 실제 선발 기록을 사용한다. 기록이 불완전한 경우에만 해당 팀의 파생 OVR 상위 11명으로 안전하게 대체한다.
- 팀 화면에는 실제 대회 평균 점유·슈팅·코너·파울·선방과 FIFA 랭킹·Elo·조·감독을 표시한다.
- 원천의 넓은 POS(GK/DEF/MID/FWD)는 전술 보드 운용을 위해 세부 포지션으로 매핑한다. 이 매핑은 공식 등록 포지션을 대체하지 않으며 `sourcePosition`에 원문 값을 유지한다.
- OVR·7개 전술 스탯은 실제 포지션·A매치·대표팀 득점·시장가치·이번 대회 출전 기록을 이용한 TACTICA 규칙 기반 지수다. EA SPORTS FC/FIFA 공식 게임 능력치가 아니다.
- 전술 성향·선발 배치·시뮬레이션 이벤트와 결과는 실제 데이터를 입력으로 한 서비스 모델 값이며 실제 경기 결과를 재현하거나 예측한다고 주장하지 않는다.

## 제출 시 표기

- 앱 `DATA · METHOD`과 결과 Markdown에는 데이터 출처·CC0 조건·가공 원칙을 함께 표기한다.
- 데이터셋의 CC0 표기를 유지하고, GitHub 원본 링크를 README와 저장소 문서에서 제공한다.
- 외부 로고·선수 사진·영상·유료 API 키는 포함하지 않는다.
