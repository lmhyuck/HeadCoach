# TACTICA 2026 출처 및 라이선스 기록

## 애플리케이션 코드

- 라이선스: `MIT` (`/LICENSE`)
- 외부 API: 사용하지 않음
- 외부 폰트·이미지·선수 사진·팀 로고: 사용하지 않음
- 아이콘: 브라우저 기본 이모지와 텍스트 기호만 사용

## 현재 데이터

- 파일: `data/world-cup-2026.json`
- 상태: CC0 공개 월드컵 2026 데이터 기반의 실제 팀·선수·대회 기록 + TACTICA 파생 전술 지수
- 적용 범위: 개막 전 FIFA 랭킹 상위 32개 본선 참가국, 팀당 26명, 총 832명
- 원천 CSV·CC0 조건·수집일·가공 범위: `docs/08-실데이터-출처-및-가공기록.md`
- FIFA 로고·선수 사진·영상·엠블럼·EA SPORTS FC/FIFA 공식 게임 능력치: 포함하지 않음
- 경기 시나리오·선발·포메이션·전술 지수·시뮬레이션 결과: 실제 공식 경기 기록이 아닌 서비스 모델 값

## 제출 전 확인 원칙

1. 대회 제공 데이터가 있거나 데이터 이용 조건이 갱신되면 그 조건을 우선 적용한다.
2. 원본 URL, 이용 조건, 수집일, 가공 범위를 `docs/08`과 앱의 `DATA · METHOD`에 일치시킨다.
3. 실제 경기 결과와 TACTICA의 가상 시뮬레이션 결과를 혼동시키지 않는다.
4. 제출 직전에 CC0 원천 저장소의 라이선스 표기와 대회 공지의 데이터·저작권 조건을 다시 확인한다.
