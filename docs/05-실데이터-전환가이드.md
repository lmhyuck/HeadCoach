# TACTICA 2026 실데이터 전환 가이드

기본 데이터는 `data/world-cup-2026.json`이며, 2026 월드컵 본선 참가국 중 FIFA 랭킹 상위 32개국의 팀·선수·대회 기록을 적용했다. 출처·가공 기준은 `docs/08-실데이터-출처-및-가공기록.md`를 기준으로 한다. 원천 CSV가 갱신되면 `scripts/build_world_cup_32_data.mjs`로 다시 생성한다.

앱 상단 `DATA · METHOD`의 `JSON 데이터 교체`는 같은 스키마를 브라우저에서 임시 검증하는 도구다. 최종 배포본은 심사자가 별도 파일을 올리지 않아도 되도록, 검증 완료된 실제 데이터 파일을 프로젝트 기본 데이터로 교체해야 한다.

## 교체 절차

1. 원본 데이터의 출처, 라이선스, 수집일을 기록한다.
2. 동일한 JSON 스키마로 정규화한다.
3. `metadata.sourceType`을 `official`로, `sourceName`을 실제 제공처로 변경한다.
4. 아래 필수 필드와 팀·선수 참조를 검증한다.
5. 각 시나리오를 다시 재생해 포메이션, 후보 명단, 교체, 결과 리포트를 확인한다.

## 필수 스키마

- `metadata.schemaVersion`, `metadata.sourceType`, `metadata.sourceName`, `metadata.lastUpdated`
- `teams`: `id`, `name`, `defaultStartingXI`, `bench`
- `players`: `id`, `teamId`, `primaryPosition`, `overall`, `attributes`
- `attributes`: `pace`, `shooting`, `passing`, `dribbling`, `defense`, `physical`, `positioning`
- `formations`, `matchScenarios`

앱 시작 시 기본 스키마 검증을 수행한다. 누락된 필수 필드는 오류로 처리해 불완전한 데이터가 조용히 화면에 노출되는 일을 막는다.

## 표기 원칙

- 실제 경기 결과와 TACTICA의 시뮬레이션 결과를 혼동하지 않도록 화면에 데이터 상태를 표기한다.
- 선수 초상, 엠블럼, 상표는 별도 사용 허가가 없는 한 포함하지 않는다.
- 결과 리포트에는 데이터 상태와 갱신 기준을 함께 남긴다.
